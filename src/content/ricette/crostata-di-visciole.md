---
titolo: Crostata di visciole
sezione: dolci
autore: giulio-marano
descrizione: >-
  Frolla friabile e confettura di visciole asprigna, chiusa dalla grata di strisce incrociate.
porzioni: 8
tempoPreparazione: 30
tempoCottura: 40
tempoRiposo: 60
difficolta: media
accessori:
  - Teglia da crostata da 24 cm, a bordo basso
  - Mattarello
  - Pellicola
  - Rotella tagliapasta
  - Carta forno
ingredienti:
  - gruppo: Per la frolla
    voci:
      - { nome: Farina 00, quantita: 300, unita: g }
      - { nome: Burro, quantita: 150, unita: g, note: freddo di frigo }
      - { nome: Zucchero, quantita: 120, unita: g, note: o zucchero a velo }
      - { nome: Uova, quantita: 1, unita: pz, note: più un tuorlo }
      - { nome: Scorza di limone, quantita: 1, unita: pz, note: "grattugiata, solo la parte gialla" }
      - { nome: Lievito per dolci, quantita: 1, unita: cucchiaino, note: raso }
      - { nome: Sale, quantita: 1, unita: pizzico }
  - gruppo: Per la farcia
    voci:
      - { nome: Confettura di visciole, quantita: 400, unita: g }
passaggi:
  - titolo: La frolla
    testo: >-
      Lavora velocemente con la punta delle dita farina e burro freddo a pezzetti finché ottieni una sabbia. Aggiungi zucchero, scorza, lievito e sale, poi uovo e tuorlo, e impasta solo quanto basta a compattare. Mani calde e troppo lavoro fanno una frolla dura.
    foto: /foto/crostata-di-visciole/passo-1.jpg
    didascalia: La sabbia di farina e burro, prima di aggiungere le uova.
  - titolo: Il riposo
    testo: >-
      Schiaccia l'impasto in un disco, avvolgilo nella pellicola e lascialo in frigo.
    durata: 60
    foto: /foto/crostata-di-visciole/passo-2.jpg
  - titolo: Il guscio
    testo: >-
      Accendi il forno a 180 °C statico. Stendi due terzi della frolla tra due fogli di carta forno a mezzo centimetro, foderaci la teglia e bucherella il fondo con la forchetta.
    foto: /foto/crostata-di-visciole/passo-3.jpg
  - titolo: La farcia e la grata
    testo: >-
      Distribuisci la confettura in uno strato uniforme. Stendi la frolla avanzata, ricava le strisce con la rotella e disponile a grata, sigillando le estremità sul bordo.
    foto: /foto/crostata-di-visciole/passo-4.jpg
    didascalia: La grata a strisce incrociate sopra la confettura.
  - titolo: La cottura
    testo: >-
      Cuoci nella parte bassa del forno finché la frolla è dorata anche sotto. Lasciala raffreddare del tutto nello stampo prima di toglierla: calda si rompe.
    durata: 40
    foto: /foto/crostata-di-visciole/passo-5.jpg
conservazione: Sotto una campana di vetro 4 giorni; il giorno dopo la frolla è migliore.
note: >-
  La confettura di visciole è la scelta di Roma; con l'amarena o con le ciliegie viene più dolce. Se la confettura è molto liquida mescolala con un cucchiaio di pangrattato perché non bagni la frolla.
