titolo: Spezzatino con le patate
sezione: secondi
autore: giulio-marano
descrizione: >-
  Bocconi di manzo cotti piano con vino e pomodoro, e le patate che finiscono di cuocere nel sugo.
porzioni: 4
tempoPreparazione: 20
tempoCottura: 120
difficolta: facile
stagione: [autunno, inverno]
accessori:
  - Casseruola dal fondo spesso con coperchio
  - Tagliere e coltello
  - Mestolo
ingredienti:
  - { nome: Spezzatino di manzo, quantita: 800, unita: g, note: "spalla o cappello del prete, a cubi di 4 cm" }
  - { nome: Patate, quantita: 600, unita: g, note: a pasta gialla }
  - { nome: Cipolla, quantita: 1, unita: pz }
  - { nome: Carota, quantita: 1, unita: pz }
  - { nome: Sedano, quantita: 1, unita: pz, note: una costa }
  - { nome: Vino rosso, quantita: 150, unita: ml }
  - { nome: Passata di pomodoro, quantita: 200, unita: ml }
  - { nome: Brodo di carne, quantita: 500, unita: ml, note: caldo }
  - { nome: Farina 00, quantita: 1, unita: cucchiaio }
  - { nome: Alloro, quantita: 2, unita: foglia }
  - { nome: Rosmarino, quantita: 1, unita: mazzetto, note: un rametto }
  - { nome: Olio extravergine, unita: q.b. }
  - { nome: Sale, unita: q.b. }
  - { nome: Pepe nero, unita: q.b. }
passaggi:
  - titolo: La carne
    testo: >-
      Asciuga i cubi di carne con la carta da cucina e infarinali leggermente. Carne asciutta rosola, carne bagnata bolle.
    foto: /foto/spezzatino-con-le-patate/passo-1.jpg
  - titolo: La rosolatura
    testo: >-
      Rosola la carne in poco olio a fuoco vivace, pochi pezzi per volta, finché è scura su tutti i lati. Mettila da parte.
    durata: 10
    foto: /foto/spezzatino-con-le-patate/passo-2.jpg
    didascalia: Pochi pezzi per volta, distanziati nella casseruola.
  - titolo: Il soffritto
    testo: >-
      Nella stessa casseruola appassisci cipolla, carota e sedano tritati, raschiando il fondo lasciato dalla carne.
    durata: 5
    foto: /foto/spezzatino-con-le-patate/passo-3.jpg
  - titolo: Vino e pomodoro
    testo: >-
      Rimetti la carne, sfuma con il vino e lascialo evaporare. Aggiungi passata, alloro, rosmarino e brodo caldo fino quasi a coprire; sala, pepa, copri e cuoci a fuoco basso.
    durata: 80
    foto: /foto/spezzatino-con-le-patate/passo-4.jpg
  - titolo: Le patate
    testo: >-
      Unisci le patate a tocchi grossi e cuoci ancora, coperto, finché sono tenere e la carne si sfalda con la forchetta. Se il sugo è troppo liquido, togli il coperchio negli ultimi 10 minuti.
    durata: 40
    foto: /foto/spezzatino-con-le-patate/passo-5.jpg
    didascalia: Le patate tenere e il sugo ristretto.
conservazione: In frigo 3 giorni; il giorno dopo è anche più buono. Si congela senza le patate.
note: >-
  Il taglio conta più di tutto il resto: servono tagli con collagene, che con la cottura lunga diventano morbidi. Il magro resta stopposo.
