titolo: Pasta col tonno
sezione: primi
autore: giulio-marano
descrizione: >-
  Il primo della dispensa: tonno sott'olio, pomodoro e capperi, pronto nel tempo di cottura della pasta.
porzioni: 4
tempoPreparazione: 10
tempoCottura: 15
difficolta: facile
accessori:
  - Pentola per la pasta
  - Padella larga
  - Scolapasta
ingredienti:
  - { nome: Spaghetti, quantita: 360, unita: g, note: o penne }
  - { nome: Tonno sott'olio, quantita: 160, unita: g, note: "sgocciolato, due scatolette" }
  - { nome: Pomodorini, quantita: 300, unita: g, note: o passata di pomodoro }
  - { nome: Capperi, quantita: 1, unita: cucchiaio, note: dissalati }
  - { nome: Aglio, quantita: 1, unita: spicchio }
  - { nome: Prezzemolo, quantita: 1, unita: mazzetto, note: tritato }
  - { nome: Olio extravergine, unita: q.b. }
  - { nome: Peperoncino, unita: q.b., note: facoltativo }
  - { nome: Sale, unita: q.b. }
passaggi:
  - titolo: L'acqua
    testo: >-
      Metti sul fuoco l'acqua per la pasta e salala quando bolle. Il sugo si fa nel tempo che serve all'acqua e alla pasta, non prima.
    foto: /foto/pasta-col-tonno/passo-1.jpg
  - titolo: Il soffritto
    testo: >-
      In padella scalda un giro d'olio con l'aglio schiacciato e il peperoncino. Quando l'aglio sfrigola uniscilo ai capperi e lasciali insaporire un minuto.
    durata: 2
    foto: /foto/pasta-col-tonno/passo-2.jpg
  - titolo: Il pomodoro
    testo: >-
      Aggiungi i pomodorini tagliati a metà, sala poco e cuoci a fuoco vivace finché si ammorbidiscono e fanno il loro sugo.
    durata: 8
    foto: /foto/pasta-col-tonno/passo-3.jpg
  - titolo: Il tonno
    testo: >-
      Togli l'aglio e unisci il tonno sgocciolato, sbriciolato con la forchetta. Scaldalo appena: se cuoce troppo diventa stopposo.
    durata: 2
    foto: /foto/pasta-col-tonno/passo-4.jpg
    didascalia: Il tonno a scaglie grosse, non ridotto in polvere.
  - titolo: Insieme
    testo: >-
      Scola la pasta al dente tenendo da parte un mestolo d'acqua di cottura, saltala in padella con il sugo allungando con l'acqua se serve. Finisci con il prezzemolo e un filo d'olio a crudo.
    durata: 1
    foto: /foto/pasta-col-tonno/passo-5.jpg
conservazione: Va mangiata subito; il tonno riscaldato perde morbidezza.
note: >-
  Niente formaggio. Se vuoi un tocco in più, una manciata di olive nere insieme ai capperi o una grattata di scorza di limone alla fine.
