titolo: Pesto di basilico
sezione: conserve
autore: giulio
descrizione: >-
  Senza cottura e senza fretta: il basilico va pestato, non frullato, o diventa nero e amaro.
porzioni: 4
unitaPorzioni: vasetti
tempoPreparazione: 25
difficolta: media
stagione: [estate]
accessori:
  - Mortaio di marmo con pestello di legno
  - Vasetti di vetro con tappo
ingredienti:
  - { nome: Basilico genovese, quantita: 60, unita: g, note: solo le foglie piccole, lavate e asciugate }
  - { nome: Pinoli, quantita: 30, unita: g }
  - { nome: Aglio, quantita: 2, unita: spicchio, note: senza anima }
  - { nome: Parmigiano reggiano, quantita: 60, unita: g, note: grattugiato }
  - { nome: Pecorino sardo, quantita: 30, unita: g, note: grattugiato }
  - { nome: Sale grosso, quantita: 1, unita: pizzico }
  - { nome: Olio extravergine d'oliva, quantita: 100, unita: ml, note: delicato, ligure se possibile }
passaggi:
  - testo: Pesta l'aglio con il sale grosso finché diventa una crema. Il sale fa da abrasivo.
    durata: 4
  - testo: Unisci i pinoli e continua a pestare fino a ottenere una pasta omogenea.
    durata: 4
  - testo: >-
      Aggiungi le foglie di basilico poche per volta, ruotando il pestello contro le pareti del mortaio con movimento circolare. Non battere: si schiacciano le cellule e il basilico ossida.
    durata: 10
  - testo: Incorpora i formaggi, poi versa l'olio a filo mescolando con il pestello dal basso verso l'alto.
    durata: 5
  - testo: Invasa premendo bene per togliere l'aria e copri la superficie con un dito d'olio.
    durata: 2
conservazione: In frigo una settimana con l'olio a coprire. Si congela in vaschette da cubetti di ghiaccio, senza formaggi (si aggiungono al momento).
note: >-
  Se usi il frullatore, tienilo in freezer prima e lavora a impulsi brevissimi: le lame scaldano e il calore è il nemico del pesto.
tag: [salse, senza cottura, estate, vegetariano]
dataInserimento: 2026-07-05
esempio: true
---
